# 第一阶段内部协作约定

本地 Go 程序由 sb 调用，同时提供不开放网络端口的计量守护模式。
账号独立 sing-box 进程；所有逻辑节点绑定分别生成独立监听端口。
认证身份必须属于一个账号，未归属旧配置在接管时停用。
北京时间自然月；上传和下载合计；没有结转；手动禁用和计量故障不随月初清除。
WARP 固定域名路由覆盖全部受管实例；出口失败不自动回退直连。
仅 root 部署，不增加系统用户。Agent/API、订阅、Web 不在本阶段。

数据库共用单写者锁。SQLite 存储期望状态与累计用量；配置回滚不能回滚用量。
计量使用 V2Ray API 全部入站累计计数，reset=false；checkpoint 和用量同事务更新。
核心内存计数异常重置时保护性停用，不把独立进程称为零丢量保证。
