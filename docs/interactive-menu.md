# 交互式管理菜单

执行不带参数的 `sb` 或 `sb enhanced` 进入中文菜单。原有带参数命令的 JSON 格式和退出码保留，方便脚本及后续 API 复用。

## 页面结构

| 主菜单 | 后续页面 |
| --- | --- |
| 1. 查询节点 | 名称与进程状态列表 → 选择节点 → 详情 → 所选账号的连接信息、分享链接或二维码 |
| 2. 账号与流量 | 数字选择账号或创建账号 → 访问策略、实际进程、上传下载、额度和账期 → 启停、额度、重置及故障恢复 |
| 3. 节点配置管理 | 导入模板并绑定、绑定、解绑、删除 |
| 4. WARP 管理 | 状态、域名列表与详情、增加/删除规则、安装、接受条款并注册、连接/断开 |
| 5. 服务管理 | 真实状态及启动、停止、重启 |
| 6. 查看日志 | 流量守护日志或所选账号日志，最近50行 |
| 7. 应用管理员 | 查看管理员名称、改名、隐藏输入并二次确认新密码 |
| 8. 使用帮助 | 命令帮助 |

每层 `0` 返回上层，主菜单 `0` 退出。操作结果按回车后返回原页面，不自动跳回主菜单。
输入结束（EOF）退出整套菜单。数据输入框的空输入按提示取消；菜单中的空输入不执行变更。
额度输入框中的 `0` 仍然表示零额度，不能访问，与返回选项区分。
TTY 进入页面时仅清理可视区，保留终端滚动历史；非 TTY 不发送清屏控制序列。

已有账号、节点及规则按数字选择。序号来自同一次快照，内部使用稳定ID；ID优先于同名记录解析。
进入详情或提交变更时重新校验对象，避免列表顺序变化影响选择。

## 状态与隐私

节点列表仅显示名称和真实实例状态，多账号节点可显示“部分运行”。账号访问策略与进程状态分别展示，
未知、启动中、停止中、故障等状态保留；进程运行不等于公网连接已验证。
服务状态使用限时批量只读查询，不启停服务；数据库快照完成并释放管理锁后才进行外部探测。

普通详情隐藏协议凭据，选择“查看连接信息”、分享链接或二维码后才展开所选账号的单个绑定。
详情不倾倒完整入站JSON、服务端私钥或管理员密码哈希。分享内容仍包含认证信息，终端滚动历史可能保留内容。
应用管理员密码与协议认证及Linux root密码独立；本轮没有为普通流量账号增加改名改密码入口。

## 流量与变更

交互额度使用十进制GB：`1 GB = 1,000,000,000 字节`，支持最多9位小数，例如300GB转换为300000000000字节。
显示按GB/MB/KB/B换算；既有数据库字节额度不重算。无限额度单独选择，仍显示实际用量。
按北京时间自然月重置、不结转。手动重置不会解除手动停用或计量故障。

影响访问或数据的变更先显示对象、范围并要求确认，空确认默认取消。
失败显示中文提示，可主动查看技术错误；导入成功但绑定失败会明确保留未绑定模板并说明后续处理。
WARP规则覆盖全部受管新旧节点，变更可能重新加载账号实例；命中规则的流量在出口故障时阻断。
Cloudflare注册继续要求输入 `ACCEPT` 接受条款。

新安装不显示迁移菜单；开发迁移入口仍须开发者模式及检测到旧安装。
